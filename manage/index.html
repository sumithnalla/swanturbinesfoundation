System Architecture & Specifications

Deployment targets and environment specifications

Application Backend

FastAPI (Python 3.13) running with native async coroutines, Pydantic v2 schemas, and standard REST JSON error contracts.

Primary Datastore

MongoDB with Motor Async Driver. Document-based persistence for campaigns, applications, users, roles, and audit trails.

Document Storage

MongoDB GridFS chunked file storage for applicant income certificates, medical records, and identity documents.

Transactional Mailer

Resend API Provider for transactional emails: applicant confirmation receipts, status change updates, and custom inquiries.

Authentication & Cryptography

Native Bcrypt password hashing with HS256 JWT stored securely in HTTP-only session cookies with CORS credential support.

Edge & Hosting

Frontend deployed on Cloudflare Pages; Backend containerized for Render web services with automatic TLS.
