# Historical project documents

These files preserve the planning, audit and migration record. Many predate the change from Render/FastAPI/MongoDB/GridFS to Cloudflare Pages/Supabase/Google Drive. They are **not** the current operating instructions or proof of present production health.

Start with the [root README](../../README.md) for the current architecture, URLs and bug workflow. Consult `MIGRATION_PROGRESS.md` for dated implementation/test notes. In particular, `PROJECT_STATE.md`, `ARCHITECTURE.md`, `DECISIONS.md`, `CHECKPOINTS.md`, `IMPLEMENTATION_PLAN.md` and the legacy `legacy-README.md` describe superseded designs.

The archived `begin-phase-6.md`, `localhost.md` and `runguide.md` had plaintext passwords in the working tree. Password lines were redacted before these documents were committed. Do not restore them or use archival credentials for production.

Some old relative links were written for the repository root and may not resolve after relocation; use the filename in this directory. The preserved documents may contain obsolete phase stop gates and outdated status assertions. Verify the source and live service before acting.
